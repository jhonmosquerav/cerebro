# assets/ — identidad visual de CEREBRO

El logo: un cerebro tejido como **grafo de nodos y aristas** — la marca dice
lo que es el sistema (un grafo declarativo de conocimiento). La "E" del
wordmark, en tres barras, evoca las aristas del grafo y las líneas del ledger.

## Archivos

| Archivo | Uso |
|---|---|
| `logo.png` | Logo completo original (1254×1254, fondo blanco). Canónico. |
| `logo-transparent.png` | Logo completo, **fondo transparente** — funciona en claro y oscuro (el que usa el README). |
| `isotype.png` | Solo el cerebro (isotipo), transparente — avatar, social preview, sello. |
| `favicon-256.png` | Isotipo a 256×256 para favicon de un sitio (p. ej. una futura página de docs). |

## Color de marca

- **Azul CEREBRO — `#4134E7`** (rgb 65 52 231). Un solo color; el logo se
  lee también en monocromo (negro sobre claro / blanco sobre oscuro).

## Notas de uso

- La **social preview** del repo (la tarjeta al compartir el enlace) se sube
  en GitHub → *Settings → Social preview*; no se versiona por git. Sirve
  `logo.png` o `isotype.png`.
- Las versiones transparentes se derivaron de `logo.png` recoloreando al azul
  de marca y usando la cobertura como alfa (bordes limpios, sin halo blanco).
- ¿Necesitas SVG? Vectoriza `logo.png` (Figma / Illustrator / vectorizer.ai);
  el trazo es geométrico y se vectoriza sin pérdida.
